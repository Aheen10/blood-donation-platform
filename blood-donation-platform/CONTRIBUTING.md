# Contributing

1. `git pull origin main` before you start work every day.
2. Create your own branch: `git checkout -b feature/<name>-<task>` (e.g. `feature/jesan-eligibility`).
3. Work only on the files named in your GitHub Issue.
4. Commit small, clear messages: `feat: add haversine distance`, `fix: ...`, `docs: ...`.
5. Push your branch and open a Pull Request into `main`. Never push to `main` directly.
6. Never commit `.env` or any API key.
